虚拟被控对象 / START–STOP MOTOR

程序在PLC里，电机在网页里。

网页发送按钮与热继电器状态，只根据PLC的 MotorCommand 显示电机。网页不执行自保持或停止逻辑。

实体PLC版需将本目录下载至CPU Web服务器后打开。普通PLCSIM V18不支持此AWP连接。

打开PLC登录页

连接后，按启动检查PLC程序。

信号方向

StopOK、OverloadOK采用健康位：正常为1，停止按下或过载时为0。全部通信使用专用DB，不写物理I区或Q区。

界面验证：手动注入电机反馈（没有PLC）

这里只验证网页动画；按启动不会替你执行PLC逻辑，不表示PLCSIM已经连接。

用自己的PLC程序完成四项检查

  1. 按下再松开启动，电机保持运行。
  2. 按下停止，MotorCommand应变0；松开停止后不自行重启。
  3. 运行中触发过载，电机停；恢复正常后仍等待重新启动。
  4. 一直按住启动时触发停止或过载，再解除，电机不能自动重启；须松开后重新启动。

画面显示的0/1是PLC反馈，不是自动评分。断线显示“反馈未知”，不把停止动画当作真实PLC已停机的证明。
