# 电子装箱工作站 · 部件与信号对照

本课承接已完成的手动点动、端部限位与单次投料，新增单箱自动控制。左工位放泡沫，右工位放电子产品，中间放空箱并接收成箱。GLB 用开口剖视箱显示七层，供网页逐步揭示。

## 工艺与证据

原始手动／自动功能图给出教学地址，HMI 截图表现工作指示和装填层序。提交包中的任务书 PLC-PKG-02 A/0 明确投料后等待、单次计数和中间到位停车。课堂设计、工作页 1 与工作页 2 要求学生区分第 3 份和第 4 份泡沫之后的去向。交互学习网页补充了中间检测的演示地址。

工程列来自提交包内 Factory I/O 2.5.0 场景的对象名、对象 I/O 标签，以及 SiemensS7PLCSIM 配置中按 PointIOKey 匹配的绑定。场景内部的 Address 序号和控制器绝对地址具有不同含义。下表的“待核对”指应在教学机驱动配置及 PLC 工程中确认。

## 浏览器接入

- **单位与坐标**　CAD 源码用毫米、Z 向上。GLB 世界坐标用米、Y 向上、X 向右、正 Z 朝正面。Station 根节点包含 CAD 向 GLB 的轴旋转，请保留。其子节点的本地坐标仍为 X 横移、Z 高度。使用内置相机 TeachingFront 可恢复授课正面斜视角。
- **定位与移动**　DatumLeft、DatumCenter、DatumRight 和 Carton 是 Station 下的同级节点。三个基准的世界位置（米）依次为 (−1.45, 0.8, 0)、(0, 0.8, 0)、(1.45, 0.8, 0)。箱体原点位于底面中心。在 Three.js 中可用 `carton.position.copy(datum.position)` 把箱体送到指定工位。箱内层随箱移动，工位和传感器保持固定。
- **层序与初始状态**　文件打开时显示成箱剖面，便于验收。空箱演示开始时分别隐藏 Carton 下的 Foam_01、Product_01、Foam_02、Product_02、Foam_03、Product_03、Foam_04，每次投料完成只揭示下一层并计一次。产品是含电路板和元件的组，控制整组 visible。货架库存对应 StockFoam_01…04、StockProduct_01…03，可独立显隐。
- **检测与指示**　点击 SensorLeft、SensorCenter、SensorRight 可选中整套检测件；点亮各组内 LeftLens、CenterLens、RightLens 可提示到位。六只 Lamp 节点均为独立灯面。网页逐灯控制时先克隆该灯的材质，再设置发光强度或颜色，避免共享材质同时变色。库存、控制按钮、运行灯默认展示外观色，由网页初始化状态。
- **工艺核验点**　每站到位停车，前后各等待 2 s。七次投放后的“泡沫／产品”为 1/0、1/1、2/1、2/2、3/2、3/3、4/3。第三件产品后须去左工位补顶层泡沫。末次投后等满 2 s，右行回中，中间检测有效时停车。灯亮 1 s、灭 1 s 为一周期，十周期后熄灭，本箱结束。

## 编辑与重建

用带 build123d 和 NumPy 的 Python 执行同目录 station.py，生成 station.glb。中文铭牌使用系统中文字库，可以通过环境变量 STATION_CJK_FONT 指定替代字体。源码中的 STOPS、DECK、carton、feeder、detector 和 console 分别控制工位基准、滚筒表面高度及各装配。滚筒线按工程中的 4 m 对象建模；其他尺寸、支架、货架细部、板件外观及站距按教学可视性确定。
